# Knowledge base

Source material for Pursuit's knowledge base. See planning/pursuit-spec.md §6.

- `sources.yaml` — web pages to fetch.
- `datasheets/` — fact sheets, product briefs.
- `documentation/` — product documentation.
- `presentations/` — decks.
- `past-rfps/` — previous RFP responses.
- `transcripts/` — webinar and video transcripts, as text files.
- `notes/` — written notes and positioning.

Supported formats: `.pdf`, `.docx`, `.pptx`, `.md`, `.txt`, plus web pages listed in
`sources.yaml`.

This folder's contents (other than this file and `sources.yaml`) are not tracked in version
control — see `.gitignore`.
